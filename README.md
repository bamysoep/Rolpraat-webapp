A full-stack web application where users can rate movies, track their viewing history, and view analytics. Administrators can manage the movie database with manual entry (since IMDB API is now paid).

## 🎯 Overview

Rolpraat is a movie rating platform that allows users to:
- Create an account and maintain sessions
- Rate and review movies
- View personal statistics (average scores, trends, viewing history)
- See general analytics (top-rated movies, community statistics)

Administrators can:
- Manually add new movies to the database
- Manage movie information (title, year, genre, director, etc.)

---

## ✨ Features

### User Features
- **Authentication**: Secure registration and login with JWT sessions
- **Movie Rating**: Score movies from 0-10 with optional reviews
- **Personal Analytics**: 
  - Average personal score
  - Movies watched over time
  - Score distribution charts
  - Viewing trends by genre/year
- **General Analytics**:
  - Top-rated movies (community)
  - Most-watched movies
  - Average scores across the platform
  - Activity statistics

### Admin Features
- **Movie Management**: Add, edit, and delete movies
- **Manual Entry**: Form-based movie addition (no API required)
- **User Administration**: View user statistics

## 🛠️ Tech Stack

### Frontend
- **Framework**: React 18 + TypeScript
- **Build Tool**: Vite
- **UI Library**: shadcn/ui + Tailwind CSS
- **State Management**: React Query (TanStack Query)
- **Routing**: React Router v6
- **Forms**: React Hook Form + Zod
- **Charts**: Recharts
- **HTTP Client**: Axios

### Backend
- **Language**: Python 3.11+
- **Framework**: FastAPI
- **Database ORM**: SQLAlchemy 2.0 + Alembic (migrations)
- **Authentication**: python-jose (JWT) + passlib (bcrypt)
- **Validation**: Pydantic V2 (built into FastAPI)
- **API Documentation**: Swagger/OpenAPI (auto-generated by FastAPI)
- **ASGI Server**: Uvicorn

### Database
- **Primary**: PostgreSQL 15+
- **Hosting**: Supabase (free tier) or Neon

### Deployment
- **Frontend**: Vercel (free tier)
- **Backend**: Vercel Serverless Functions (Python support) or Render
- **Database**: Supabase or Neon (free tier)
- **Total Cost**: $0/month 🎉

```
│  │ Frontend │──│ API │──│ Backend  │   │

│  └──────────┘  └─────┘  └────┬─────┘   │
└─────────────────────────────────┬───────┘
                                  │
                         ┌────────▼────────┐
                         │   PostgreSQL    │
                         │   (Supabase)    │
                         └─────────────────┘
```

### Authentication Flow
```
User → Login/Register → Backend validates → JWT issued
     → JWT stored in localStorage
     → Subsequent requests include JWT in Authorization header
     → Backend verifies JWT → Access granted
```

## 🗄️ Data Model

### SQLAlchemy Models

```python
# app/models/user.py
from sqlalchemy import Boolean, Column, String, DateTime
from sqlalchemy.dialects.postgresql import UUID
from sqlalchemy.orm import relationship
from sqlalchemy.sql import func
import uuid
from app.database import Base

class User(Base):
    __tablename__ = "users"

    id = Column(UUID(as_uuid=True), primary_key=True, default=uuid.uuid4)
    email = Column(String, unique=True, nullable=False, index=True)
    username = Column(String, unique=True, nullable=False, index=True)
    password_hash = Column(String, nullable=False)
    is_admin = Column(Boolean, default=False, nullable=False)
    created_at = Column(DateTime(timezone=True), server_default=func.now())
    updated_at = Column(DateTime(timezone=True), onupdate=func.now())

    # Relationships
    scores = relationship("Score", back_populates="user", cascade="all, delete-orphan")
    movies_added = relationship("Movie", back_populates="created_by")


# app/models/movie.py
from sqlalchemy import Column, String, Integer, Text, ForeignKey, DateTime
from sqlalchemy.dialects.postgresql import UUID, ARRAY
from sqlalchemy.orm import relationship
from sqlalchemy.sql import func
import uuid
from app.database import Base

class Movie(Base):
    __tablename__ = "movies"

    id = Column(UUID(as_uuid=True), primary_key=True, default=uuid.uuid4)
    title = Column(String, nullable=False, index=True)
    year = Column(Integer, nullable=False, index=True)
    director = Column(String, nullable=True)
    genres = Column(ARRAY(String), nullable=True)  # PostgreSQL array
    description = Column(Text, nullable=True)
    poster_url = Column(String, nullable=True)
    imdb_id = Column(String, unique=True, nullable=True)
    created_by_id = Column(UUID(as_uuid=True), ForeignKey("users.id"), nullable=False)
    created_at = Column(DateTime(timezone=True), server_default=func.now())
    updated_at = Column(DateTime(timezone=True), onupdate=func.now())

    # Relationships
    created_by = relationship("User", back_populates="movies_added")
    scores = relationship("Score", back_populates="movie", cascade="all, delete-orphan")


# app/models/score.py
from sqlalchemy import Column, ForeignKey, Numeric, Text, DateTime, Date, UniqueConstraint
from sqlalchemy.dialects.postgresql import UUID
from sqlalchemy.orm import relationship
from sqlalchemy.sql import func
import uuid
from app.database import Base

class Score(Base):
    __tablename__ = "scores"

    id = Column(UUID(as_uuid=True), primary_key=True, default=uuid.uuid4)
    user_id = Column(UUID(as_uuid=True), ForeignKey("users.id", ondelete="CASCADE"), nullable=False, index=True)
    movie_id = Column(UUID(as_uuid=True), ForeignKey("movies.id", ondelete="CASCADE"), nullable=False, index=True)
    score = Column(Numeric(3, 1), nullable=False)  # 0.0 to 10.0
    review = Column(Text, nullable=True)
    watched_date = Column(Date, nullable=True)
    created_at = Column(DateTime(timezone=True), server_default=func.now())
    updated_at = Column(DateTime(timezone=True), onupdate=func.now())

    # Relationships
    user = relationship("User", back_populates="scores")
    movie = relationship("Movie", back_populates="scores")

    # Constraints
    __table_args__ = (
        UniqueConstraint('user_id', 'movie_id', name='unique_user_movie_score'),
    )
```

### Entity Relationships
- **User** ↔ **Score**: One-to-Many (user can rate multiple movies)
- **Movie** ↔ **Score**: One-to-Many (movie can be rated by multiple users)
- **User** → **Movie**: One-to-Many (admin creates movies)

## 🚀 Development Setup

### Prerequisites
- Node.js 20+ and npm/pnpm
- PostgreSQL (or use free Supabase instance)
- Git

### 1. Clone Repository
```bash
git clone https://github.com/yourusername/rolpraat-webapp.git
cd rolpraat-webapp
```

### 2. Backend Setup
```bash
cd backend

# Create virtual environment
python -m venv venv
source venv/bin/activate  # On Windows: venv\Scripts\activate

# Install dependencies
pip install -r requirements.txt

# Create .env file
cp .env.example .env

# Edit .env with your database URL:
# DATABASE_URL="postgresql://user:password@localhost:5432/rolpraat"
# JWT_SECRET="your-super-secret-jwt-key"
# JWT_ALGORITHM="HS256"
# JWT_EXPIRE_MINUTES=1440

# Run Alembic migrations
alembic upgrade head

# Start backend
uvicorn app.main:app --reload  # Runs on http://localhost:8000
```

### 3. Frontend Setup
```bash
cd ../frontend
npm install

# Create .env file
echo "VITE_API_URL=http://localhost:8000/api" > .env

# Start frontend
npm run dev  # Runs on http://localhost:5173
```

### 4. Access Application
- Frontend: http://localhost:5173
- Backend API: http://localhost:8000/api
- API Docs (Swagger): http://localhost:8000/docs
- Alternative Docs (ReDoc): http://localhost:8000/redoc

## ☁️ Deployment

### Free Tier Deployment (Recommended)

#### Option 1: Vercel + Supabase (Simplest - $0/month)

**Database Setup (Supabase)**
1. Go to [supabase.com](https://supabase.com)
2. Create new project (free tier: 500MB database)
3. Copy connection string (Settings → Database → Connection String)

**Backend (Vercel Python Functions)**
1. Create `backend/vercel.json`:
   ```json
   {
     "builds": [{ "src": "app/main.py", "use": "@vercel/python" }],
     "routes": [{ "src": "/(.*)", "dest": "app/main.py" }]
   }
   ```
2. Push code to GitHub
3. Import backend to Vercel:
   - Root Directory: `backend`
   - Framework: Other
4. Add Environment Variables:
   ```
   DATABASE_URL=your-supabase-connection-string
   JWT_SECRET=your-random-secret-key
   JWT_ALGORITHM=HS256
   ```

**Frontend (Vercel)**
1. Create new Vercel project
2. Root Directory: `frontend`
3. Framework: Vite
4. Add env: `VITE_API_URL=https://your-backend.vercel.app/api`

**Note**: For a more robust Python backend deployment, consider using **Render** (free tier with persistent instances) instead of Vercel serverless.

#### Option 2: Render (Better for Python - Recommended)
**Why Render for Python?**
- Persistent Python server (not serverless)
- No cold starts
- Free tier available
- Better for FastAPI than Vercel

**Setup:**
1. Push to GitHub
2. Create **Web Service** on Render:
   - Build Command: `pip install -r requirements.txt && alembic upgrade head`
   - Start Command: `uvicorn app.main:app --host 0.0.0.0 --port $PORT`
3. Create **Static Site** for frontend:
   - Build Command: `npm install && npm run build`
   - Publish Directory: `dist`
4. Add environment variables to both services

### Database Hosting Options (Free Tier)
- **Supabase**: 500MB, unlimited API requests
- **Neon**: 10GB, serverless PostgreSQL
- **Railway**: $5 credit/month (PostgreSQL in same network as app)

## 📚 API Documentation

### Authentication
```
POST   /api/auth/register    - Register new user
POST   /api/auth/login       - Login and get JWT token
GET    /api/auth/me          - Get current user (protected)
```

### Movies
```
GET    /api/movies           - Get all movies (with pagination)
GET    /api/movies/:id       - Get movie by ID
POST   /api/movies           - Create movie (admin only)
```

```
POST   /api/scores           - Submit/update score (protected)
GET    /api/scores/user      - Get current user's scores (protected)
```

## 🎯 Key Design Decisions

### Why Python + FastAPI?
- **Fast Development**: Python's simplicity + FastAPI's modern features
- **Auto Documentation**: Swagger UI and ReDoc generated automatically
- **Type Safety**: Pydantic models with validation
- **Performance**: Async support, comparable to Node.js
- **Data Science Ready**: Easy integration with Pandas/NumPy for future analytics

### Why SQLAlchemy?
- **Industry Standard**: Most mature Python ORM
- **Flexibility**: Raw SQL support when needed
- **Alembic**: Robust migration system
- **Type Support**: Works well with Pydantic

### Why Vercel for Free Hosting?
- **Zero Config**: Auto-detects frameworks
- **Serverless Functions**: Backend API endpoints scale automatically
- **Edge Network**: Fast global CDN
- **Free Tier**: Generous limits for hobby projects
- **GitHub Integration**: Auto-deploy on push

### Why JWT over Sessions?
- **Stateless**: No server-side session storage needed
- **Scalability**: Works with serverless functions
- **Simple**: No Redis/database for session management
- **Mobile-Ready**: Easy to use in future mobile apps

### Frontend State Management
- **React Query** for server state (caching, refetching, optimistic updates)
- **React Context** for auth state
- **URL Search Params** for filters/pagination
- No global state library needed (Zustand/Redux) for this app size

## 🔒 Security Considerations

- ✅ Passwords hashed with bcrypt (12 rounds)
- ✅ JWT tokens with expiration (24 hours)
- ✅ HTTP-only cookies option (more secure than localStorage)
- ✅ Input validation with Zod on both frontend and backend
- ✅ SQL injection prevention (Prisma ORM)
- ✅ CORS configured for specific frontend domain
- ✅ Rate limiting on auth endpoints (express-rate-limit)
- ✅ Helmet.js for security headers
